## Working conventions that bit this session

- Tests: scoped during a slice; full `pnpm typecheck && pnpm lint && pnpm test --run` once before commit.
  If tests die on `localhost:51214`, run `pnpm exec prisma dev start app`.
- Stage explicit file paths only. Never push to `main` without asking.
- A git stop-hook reported "unpushed commits" falsely: the clone's fetch refspec only covered `main`, so
  the pushed branch had no tracking ref. Fixed locally with a refspec; a fresh clone needs the same if
  it reappears (`git config --add remote.origin.fetch '+refs/heads/<branch>:refs/remotes/origin/<branch>'`).
